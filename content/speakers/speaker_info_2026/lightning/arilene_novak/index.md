### API made simple: automating data access in R
Lighting Talk, 3:05 - 3:40 PM

APIs (Application Programming Interfaces) are useful tools for automating data retrieval and integrating external datasets into R workflows. This lightning talk will demonstrate how to use APIs to access data. 

Key topics:

* Secure authentication using the httr and keyring packages
* Retrieving data through GET and POST requests and troubleshooting common API errors
*Parsing JSON and other response formats using jsonlite and readr

By highlighting challenges such as credential management, error handling, and data transformation, this talk will give attendees actionable techniques they can immediately incorporate into their own R projects.
